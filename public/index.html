v1.2.1

Riwayat pembaruan fitur dan perbaikan sistem TugasKu

v1.2.1 Rilis Saat Ini
25 September 2026
  • Auto-scan Rangkuman Pribadi: Membuka tab Rangkuman Pribadi kini otomatis memindai seluruh mata kuliah pekan aktif secara langsung tanpa perlu klik manual.
  • Sakelar Nomor HP pada Draft: Tombol toggle di header draft untuk memilih mencantumkan nomor HP (@628...) atau nama mahasiswa bersih.
  • Sakelar Nomor Urut pada Draft: Tombol toggle untuk memilih format baris nomor urut (1, 2, 3) atau format tanda bullet (•).
  • Indikator Pemindaian Dinamis: Tampilan status pemindaian real-time pada tabel rangkuman saat data sedang dimutakhirkan.
v1.2.0
21 September 2026
  • Auto-scan saat ganti mata kuliah: Draf grup matkul langsung memindai otomatis saat memilih mata kuliah atau pertemuan baru.
  • Status kuesioner pribadi: Menampilkan status pengisian kuesioner pada tabel Rangkuman Pribadi untuk kelengkapan absensi valid (Fordis, Penugasan, Posttest, Kuesioner).
  • Penamaan ekspor CSV dinamis: Nama berkas dan lembar kerja Excel disesuaikan dengan kode kelas aktif (misal Data_Mahasiswa_05TPLE001.csv).
  • Indikator versi sistem: Menampilkan nomor versi pada sidebar serta riwayat pembaruan untuk verifikasi rilis.
  • Sinkronisasi akun lintas kelas: Daftar mata kuliah diperbarui otomatis dari LMS MENTARI saat login dengan akun baru.
  • Kompatibilitas format Excel: Pemisah kolom terstandarisasi dengan UTF-8 BOM dan pencegahan konversi NIM ke notasi ilmiah.
v1.1.0
20 September 2026
  • Pengaturan kelompok daring/luring: Penyesuaian jadwal daring dan tatap muka per mata kuliah di panel pengaturan.
  • Masking kredensial: Perlindungan token bot Telegram pada antarmuka pengaturan dan skrip ekspor bersih npm run export:clean.
  • Integrasi browser Chrome lokal: Menggunakan instance Google Chrome terpasang untuk mengurangi kebutuhan unduhan biner terpisah.
v1.0.0
Awal September 2026
  • Rilis awal: Pemindai keaktifan forum dan posttest LMS MENTARI, penanganan sesi browser, draf pesan WhatsApp kelas, dan notifikasi bot Telegram.
